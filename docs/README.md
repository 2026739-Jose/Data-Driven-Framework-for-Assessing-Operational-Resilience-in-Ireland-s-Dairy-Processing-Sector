# A Data-Driven Framework for Assessing Operational Resilience in Ireland's Dairy Processing Sector
**Seasonal Milk Forecasting, Fuel-Cost Sensitivity, and Predictive Maintenance Risk**

## Project Overview
This project analyzes the operational challenges caused by extreme seasonality in the Irish dairy sector, where peak milk intake can reach up to six times regular monthly volumes. The core problem is data fragmentation: key information about milk production, weather conditions, fuel costs, and plant maintenance is scattered across disconnected sources. This project aims to integrate public and industry data into a unified framework to help decision-makers anticipate operational and financial risks.
